## 2. 十轮资源生命周期

每轮执行：进入 3D → 1F/2F/1F → 连续旋转、平移、缩放 → 退出 → 再次进入 3D。第一轮 10 次循环中，退出阶段均观察到 `canvasCount=0`、重入阶段为 1 个 renderer；重入后的 WebGL 纹理约 567 张，geometry 约 1,470 个，shader program 22 个；可见网格 1,524、绘制调用 2,772、三角形 703,810 保持不变。

补充预热采样期间开发服务器发生过一次热更新，视图按钮在部分轮次保持 3D canvas；这些轮次只用于观察缓存累计计数，不用于判断退出时 renderer 是否已销毁。完整退出/重入结论以第一轮 10 次循环为准。

## 3. 绘制调用来源诊断

当前实时快照：1,524 个可见网格、2,772 次绘制调用、7,257 个可见 geometry group、0 个多材质数组网格、239 个透明网格、52 个双面网格、25 个显式 renderOrder 网格、7 盏实时灯和 0 盏阴影灯。

运行时对象的 `name` 和 `userData` 在当前构建中没有稳定保留到渲染树，因此无法安全把每一次 WebGL draw 反推出“墙/柜门/家具”对象类别；下面是可复现的材质族/几何组贡献代理，不把 geometry group 数冒充实际 draw call：

| 材质族 | 可见网格 | geometry groups | 三角形代理 | 透明网格 | 是否可直接实例化 |
|---|---:|---:|---:|---:|---|
| MeshStandardMaterial（家具、建筑、辅助层混合） | 1,174 | 5,572 | 341,108 | 46 | 否，类别混杂 |
| blackTitanium（拉手、栏杆、门窗框、灯具金属件混合） | 150 | 875 | 3,180 | 49 | 暂不直接做，需对象标签 |
| warmOak（柜门、门扇、墙板、地板混合） | 64 | 369 | 738 | 27 | 否，UV 方向不同 |
| warmWhiteMineral | 48 | 258 | 518 | 45 | 否，建筑/家具混合 |
| travertine | 28 | 168 | 336 | 25 | 否，纹理方向和裁切关系不同 |
| MeshPhysicalMaterial / clearGlass | 39 | 175 | 7,576 | 39 | 否，透明/物理材质 |

没有阴影灯并不等于绘制调用应接近可见网格数：当前差额主要来自 geometry groups、透明/双面材质、辅助/轮廓层以及同一完整模型中大量细分构件；阴影 pass 在本配置为 0，不是主要来源。

第三阶段候选清单只能先列为：完全相同的柜门拉手、栏杆立柱/扶手、重复灯具外壳、完全相同的装饰格栅。每一类都必须先补稳定对象标签，再验证选择、高亮、隐藏、楼层切换和定位后才能实例化；本阶段没有执行。

## 4. 材质实例键值差异

当前缓存上限为 192 条。阶段二运行中各键的唯一值数量如下：

| 键 | 唯一值 |
|---|---:|
| token | 10 |
| color | 30 |
| roughness | 28 |
| metalness | 9 |
| opacity | 10 |
| transmission / thicknessMm | 4 / 4 |
| clearcoat / clearcoatRoughness | 5 / 5 |
| normalStrength | 8 |
| UV repeatX / repeatY | 112 / 49 |
| UV rotation | 2 |
| side / depthWrite | 2 / 2 |
| clippingPlanes | 1 |
| object shader 参数（emissive、emissiveIntensity、envMapIntensity） | 各 1 |

最大的材质键分裂来源是 UV repeatX/repeatY，其次是颜色、roughness 和 normalStrength；这正是不能为了降低实例数而把不同方向、不同重复比例的木材强行合并的原因。选中状态不进入 PBR canonical key，而是通过选择边界/辅助层表达。

## 5. 前台 FPS

本次 in-app 浏览器无法保证测试页始终是系统前台可见窗口；同一窗口下的 rAF 仍受后台调度影响。阶段一与阶段二各有单次快照，但不作为阶段间 FPS 结论，也没有把 7 FPS 左右的后台读数当成优化成功或回退。

2.5 阶段不修改 FPS 参数，第三阶段前仍应在可确认前台的环境中另行测量。
