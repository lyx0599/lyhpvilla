# 第二阶段视觉资源清单

本阶段没有引入外部位图、GLB、品牌模型或第三方字体，因此没有新增下载体积与外部授权依赖。

所有木材、布艺、皮革、石材、墙漆、微水泥、金属、玻璃和陶瓷表面均由浏览器运行时程序化生成 Base Color、Normal、Roughness 与 AO 回退纹理。生成器代码随项目发布，授权沿用本项目代码授权；每套纹理按质量档位生成 128×128 或 256×256 的 CanvasTexture，不产生网络请求，也不写入工作区数据。

加载策略：材质组件按对象角色与当前质量档位惰性生成，并按材质、颜色、重复比例与档位进行会话级共享，避免每块柜门或坐垫重复分配四张 GPU 纹理。桌面高质量档使用 256×256，平衡档可使用 128×128；透明玻璃使用物理透射材质，其他表面使用标准 PBR 材质。资源不可用或浏览器无法创建 Canvas 时，材质自动退回既有颜色、roughness 与 metalness，不阻塞场景。
