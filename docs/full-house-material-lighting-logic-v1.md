# 全屋统一材质与灯光逻辑 v1

## 1. 总原则

- 2D 户型与已确认的 3D 建筑模型是空间真值；写实渲染只用于提取材质、灯光、软装和摄影气质，不反向修改墙体、楼梯、门窗或房间关系。
- 全屋只维护一套 canonical PBR 材质身份、一套灯具家族和一套场景控制结构。
- 楼层不创建互不相干的材质库。楼层差异通过 `floor profile` 表达，只允许改变材质配比、亮度、曝光和功能灯需求。
- 除非材料的物理属性确实不同，不建立 `1F-*`、`B1-*` 等楼层专属材质 token。

## 2. 全屋母材质

优先复用当前 canonical token：

| Token | 全屋统一含义 | 主要用途 |
| --- | --- | --- |
| `warmWhiteMineral` | 暖象牙矿物墙面 | 大面墙、顶面、同墙色踢脚线 |
| `warmOak` | 自然浅暖橡木 | 木饰面、柜体、扶手、家具木构件 |
| `darkWalnut` | 低饱和胡桃木 | 局部背景、重点木作、1F 公区强调面 |
| `travertine` | 米色洞石 | 重点墙、台面、局部石材构件 |
| `warmGreyStone` | 暖灰石材 | 台面、湿区和局部地面 |
| `microCement` | 暖燕麦微水泥 | 地下层及连续地坪 |
| `beigeFabric` | 燕麦米灰织物 | 沙发、床、地毯及软包 |
| `blackTitanium` | 深古铜/黑钛细框 | 栏杆、门窗框、灯具和收边 |
| `clearGlass` | 低铁透明玻璃 | 栏杆、柜门和隔断 |

如果要根据效果图增加资源，应作为上述物理身份的校准版本或 showroom resource，而不是复制一套新的楼层材质身份。效果图保留为参考缩略图；PBR 基色必须先去除灯光偏色，不能直接吸取 2700–3000 K 画面的像素颜色。

## 3. 楼层配置规则

- `1F`：全屋母体系的公共空间高配版。暖象牙墙面为底，低饱和胡桃木和洞石承担重点面，自然光权重最高。
- `B1`：同一母体系的明亮地下层版本。暖象牙墙面和浅橡木比例提高，深胡桃木只用于乐器墙等局部；连续浅暖地坪降低地下空间压迫感。
- `2F`：同一母体系的安静私密版本。降低石材和深木比例，提高浅橡木、织物和低对比墙布比例。
- `B2`：同一母体系的休闲社交版本。允许增加深木、暖灰石材和低照度重点光，但不更换材质身份或灯光控制逻辑。

## 4. 全屋灯具家族与色温规则

统一复用 `lib/lighting-design.ts` 中的灯具家族：

- 基础照明：`wide-downlight` / `deep-cup-downlight`，3000 K，CRI ≥ 90；厨房、洗衣、镜前及精细操作区 CRI ≥ 95。
- 重点照明：`adjustable-spot` / `narrow-wallwasher`，2700 K，18–24°，低眩光。
- 柜内与柜下灯：`cabinet-strip` / `under-cabinet-strip`，3000 K，CRI ≥ 95，隐藏铝槽、无可见灯珠。
- 氛围灯：`curtain-strip`、装饰吊灯和阅读灯，2700 K，可调光。
- 楼梯与起夜灯：`step-light` / `night-light`，2700 K，低位向下遮光。
- 湿区镜前灯：`mirror-light`，3000 K，CRI ≥ 95，IP44 或以上。

灯光层级固定使用：`ambient`、`task`、`accent`、`decorative`、`cabinetStrip`、`mirrorLight`、`outdoor`。不得为不同楼层另造同义层级。

## 5. 全屋场景结构

每层都使用相同的五类场景，允许显示名称按房间用途调整：

1. `daylight`：白天自然光为主，人工光低亮度补偿。
2. `daily`：日常均衡照明。
3. `activity`：楼层主要活动场景；1F 可显示“晚餐/社交”，B1 可显示“阅读/活动”，2F 可显示“休息”，B2 可显示“观影/休闲”。
4. `night`：夜间低照度和起夜安全照明。
5. `cleaning`：清洁、洗衣和维护所需的高照度场景。

场景 ID、控制组引用方式和调光逻辑必须一致；楼层只覆盖各控制组的亮度百分比。

## 6. 3D 摄影表现

- 全屋统一使用 ACES 色调映射、中性白平衡、克制高光和柔和阴影。
- 楼层曝光只做小范围补偿：地下层略提高环境补光，1F 保留自然光层次，卧室层降低对比度。
- 编辑模式与写实展示模式共用材质身份；展示模式只提高纹理质量、阴影、反射和后期质量。
- 不允许通过改变相机广角、拉伸空间或删除墙体来接近效果图。

## 7. 实施边界

- 共享文件：`lib/material-system.ts`、`lib/showroom-material-resources.ts`、`lib/lighting-design.ts` 及公共 3D 渲染组件。
- 楼层配置：workspace 中对应楼层的表面绑定、家具材质 token、灯具位置、控制组、场景亮度和摄影 profile。
- 多任务同时工作时，由一个任务先完成共享母体系；其他楼层任务随后只消费共享 token，避免并发覆盖公共文件。

## 8. 验收

- 同一材质在不同楼层拥有同一 token、真实尺寸、UV 方向和物理参数。
- 同类灯具在不同楼层拥有相同家族、色温和层级语义。
- 各楼层五类场景结构一致，只有亮度及开启组不同。
- 2D 材料表、3D 模型和施工导出读取同一材质身份。
- 固定机位与自由移动视角都保持成立，不依赖单张效果图的偶然细节。
