## 全屋共享现代自然语言

- 墙顶基底：暖象牙/暖白矿物墙面，低反光、低对比。
- 地面基底：低对比暖灰石材或微水泥；B2允许略深、略有矿物云纹，但不做镜面高光。
- 浅木：自然浅橡木或浅白蜡木，用于玄关、格栅、轻量木作和局部展示框。
- 深木：低饱和深胡桃木，用于影音低柜、大板桌、水吧和展示柜内龛；避免红木色和高亮清漆。
- 石材：奶油洞石/暖灰石材，用于茶几、水吧台面和少量背景板。
- 金属：香槟古铜为主要收口；黑钛只用于结构脚、栏杆和少量设备边框。
- 玻璃：超白玻璃、烟灰玻璃、长虹/压花玻璃按功能使用。
- 软包：B2主沙发使用黑色哑光头层牛皮；坐垫保留自然褶皱和宽座软包感。
- B2与1F共享材质身份，但B2提高深胡桃木、烟灰玻璃、黑皮革和古铜占比；不复制1F家具造型。

## 灯光母规则与B2覆盖

共享规则：

- 基础/功能光：3000K。
- 重点/氛围/低位光：2700K。
- 柜内、水吧、桌面等显色要求高的区域：CRI ≥ 95；其余室内光 CRI ≥ 90。
- 深杯防眩、隐藏灯带、不可见光源；禁止用纯环境光把整个B2均匀照亮。
- 效果图用于确定层级与明暗关系，最终照度和配光需由灯具光通量、IES和现场材质样板校准。

| 灯光组 | 色温 | B2用途 |
|---|---:|---|
| ambient | 3000K | 活动区、桌区、观影区基础照明 |
| task | 3000K | 大板桌、水吧、玄关换鞋/挂衣 |
| accent | 2700K | 电视墙、纪念品柜、酒柜、柱面重点光 |
| decorative | 2700K | 顶面弧形灯槽、悬浮阴影光、柱线光 |
| cabinetStrip | 3000K | 玄关、纪念品柜、酒柜、水吧感应或分组灯带 |
| lowLevel/step | 2700K | 楼梯踏步、夜间通道和入户低位安全光 |

## B2场景覆盖

场景沿用全屋统一 schema，只覆盖B2控制组亮度，不创建孤立场景逻辑。

| 场景 | 建议层级 |
|---|---|
| 日常 | ambient 55–65%；task 40%；accent/cabinet 30–40%；decorative 30% |
| 聚餐/活动 | 大板桌与水吧 task 70–80%；活动区 ambient 55–65%；展示柜 40–50% |
| 观影 | 电视区 ambient 0–10%；顶面/悬浮灯槽 10–20%；低位光 10%；关闭会反射到屏幕的射灯 |
| 入户/迎宾 | 玄关感应灯 50–60%；楼梯低位光 25%；电视墙与展示柜背景光 20–30% |
| 夜间 | 仅楼梯、入户和通道低位光 5–15%，避免直视光源 |
| 清洁 | 3000K基础光与任务光100%，重点/氛围光可关闭 |

## 并发实施边界

- 共享材质身份、showroom资源、灯具家族与场景schema由全屋母体系维护。
- B2只维护自身家具的材质绑定、按部件覆盖、几何细化、灯光点位与楼层亮度profile。
- B2实施不得改动1F家具、1F房间、1F机位和1F灯光控制组。
- 公共文件稳定前，B2不修改同一区域；完成后先核对token/scene ID，再落地绑定。
